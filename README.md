# 김경수 포트폴리오

GitHub Pages로 호스팅하는 정적 포트폴리오 사이트입니다. 빌드 과정 없이 `index.html`과 `style.css`만으로 동작합니다.

## 배포

1. GitHub에 `<username>.github.io` 저장소(또는 아무 저장소)를 만들고 이 폴더를 push합니다.
2. 저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main` / `(root)`로 설정합니다.

## 로컬 미리보기

`index.html`을 브라우저로 바로 열면 됩니다.
