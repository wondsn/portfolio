01 About

TmaxOS와 TmaxAI를 거쳐 현재 지마켓에서 판매자에게 서비스와 데이터를 제공하는 백엔드 개발자로 일하고 있습니다. 판매자에게 판매 인사이트를 주는 통계 데이터와 서비스를 만들고 있으며, 판매자센터 로그인·판매자 정보 페이지와 이벤트 프로모션 데이터 파이프라인의 개발과 유지보수를 맡고 있습니다.

Tmax에서는 TmaxOS에 들어가는 UI 프레임워크를 개발했고, TmaxAI에서는 챗봇 빌더 서비스의 백엔드를 개발했습니다. 꾸준한 코드 리뷰로 제품의 안정성을 높이고 부족한 점을 보완하며 성장하고 있고, 팀의 개발 프로세스와 문화를 개선하는 일에도 힘쓰고 있습니다.

  • Seller Data Platform

    Databricks · Spark · Elasticsearch로 통계·캠페인 데이터 파이프라인 구축

  • Backend Services

    Kotlin/Java · Spring Boot · Kafka 기반 판매자센터 서비스 개발

  • Systems Foundation

    C++ UI 프레임워크와 Win32 호환 레이어 설계 경험
